# ⚠️ Dados SIMULADOS: demonstração do processo de análise

Os arquivos desta pasta **não são resultados de teste com usuários**. Os participantes `S01`–`S05` não existem.
Os valores foram escritos pela equipe só para mostrar que o fluxo **coleta → CSV → analisador → relatório** funciona de ponta a ponta.
A planilha usa as colunas do modelo do professor, e o SUS usa o formato exportado pelo Google Forms.

| Arquivo | Conteúdo |
|---|---|
| [SIMULADO-observacao.csv](SIMULADO-observacao.csv) | Planilha de observação simulada (5 × 7 tarefas) |
| [SIMULADO-sus-google-forms.csv](SIMULADO-sus-google-forms.csv) | Respostas SUS simuladas, no formato do Google Forms |
| [../evidencias/DEMONSTRACAO-SIMULADA.txt](../evidencias/DEMONSTRACAO-SIMULADA.txt) | Saída real do analisador sobre esses dados simulados |

Esses números **não** são usados no [relatório final](../06-relatorio-final.md) como resultado do teste.
Os resultados reais dependem das sessões com pessoas (planilhas `03-*.csv` e `04-*.csv`).
